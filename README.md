# Meu Portfólio Profissional
 ## 📌 Sobre este Projeto
 Este repositório contém o código-fonte do meu portfólio pessoal, desenvolvido como atividade acadêmica no curso de Desenvolvimento de Sistemas. O objetivo do trabalho foi construir uma página web para apresentar meu perfil, as tecnologias que estou estudando e os projetos que venho desenvolvendo ao longo do curso.

 - *📂 Repositório:* https://github.com/simonearaujo-dev-sys/meu-portfolio-profissional

 ## 🛠️ Tecnologias Utilizadas
 - *HTML5* — Estruturação de conteúdo
 - *Bootstrap 5* — Layout responsivo e componentes prontos
 - *CSS3* — Estilização personalizada
 - *GitHub Pages* — Hospedagem gratuita da página
 - *Google Slides* — Ferramenta de apresentação utilizada para exposição dos projetos
 ## 📋 Estrutura da Página
 - *Página Inicial* — Apresentação pessoal e carrossel de imagens
 - *Projetos* — Cards com descrição dos trabalhos desenvolvidos
 - *Contato* — Links para GitHub, LinkedIn e envio de e-mail
 ## ✨ Diferenciais
 - Carrossel de imagens na página inicial, semelhante a uma apresentação de slides
 - Apresentação complementar feita no Google Slides com detalhes dos projetos
 - Layout responsivo — funciona em celular, tablet e computador
 - Links funcionais para redes profissionais
 - Código organizado e estruturado em seções
